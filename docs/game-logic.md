# 보드를 타보자! 주요 로직

30초 롱보드 댄싱. 규칙은 `js/game.js`의 상태 `G`가 담당하고, Three.js는 그 상태를 자세와 배경으로 그린다. 한 프레임은 `update(dt)` → `render3d` → `hud` 순서다. `dt`는 최대 0.05초로 자른다.

## 한 판

1. 시작 화면(`title`)에서 닉네임, 스팟, 데크, 휠을 고른다. 닉네임이 없으면 시작하지 않는다.
2. `start()`가 `G`를 `play`로 새로 만든다. 속도 0.35, 남은 시간 30초, 위치는 테일.
3. 플레이 중 걷기, 푸시, 트릭으로 콤보를 쌓고 확정하면 점수에 들어간다.
4. 시간이 0이 되면 `endSession()`. 넘어지는 중이 아니면 남은 콤보를 확정하고 `over`로 바꾼다.
5. 결과 오버레이, 결과 카드, 랭킹 전송, 공유 링크가 이어진다.

WebGL 렌더러를 만들지 못하면 시작 화면 대신 오류 오버레이를 보여주고 루프를 돌리지 않는다.

## 상태

| 필드 | 의미 |
| --- | --- |
| `mode` | `title` / `play` / `over` |
| `t` | 남은 초. 플레이 중에만 감소 |
| `v` | 속도 0~1. 초당 0.055씩 감소. 푸시 중반에 +0.24, 상한 1 |
| `worldX` | 보드가 굴러간 거리(px). `v * 300 * dt`만큼 증가 |
| `pos` | 발 위치. 0 테일, 1 가운데 뒤, 2 가운데 앞, 3 노즈 |
| `act` | 진행 중인 동작. 없으면 입력을 바로 받는다 |
| `combo` | `{pts, n, names, counts}` |
| `fever`, `gauge` | 피버 남은 초, 게이지 0~1 |
| `facing` | 180° 몸 회전 트릭마다 뒤집힌다 |

`title`과 `over`에서는 배경만 굴러간다. `over`는 속도가 초당 0.4씩 줄어든다.

## 입력

버튼과 키보드는 같은 `doInput`으로 들어간다.

| 입력 | 키 | 조건 |
| --- | --- | --- |
| 뒤로 / 앞으로 | ← → | 테일~노즈 한 칸. 한 스텝 240ms |
| 푸시 | ↑, Z | 테일에서만. 먼저 콤보를 확정 |
| 트릭 1·2·3 | 1 2 3, J K L, Space는 1번 | 현재 칸의 슬롯. 최소 속도 미만이면 거절 |

동작 중 들어온 입력은 `queue`에 하나 저장했다가 동작이 끝나면 실행한다. 넘어진 중, 고스트라이드, 피봇, 행텐 미터 중에는 큐에 넣지 않는다. 고스트라이드 달리는 중과 행텐 미터 중에는 슬롯 버튼이 그 동작 전용이다.

플레이가 아닐 때 Enter, Space, R은 시작(다시하기)이다. V는 옆 시점과 뒤 시점을 바꾼다. 입력란에 포커스가 있으면 키는 무시한다.

## 칸별 트릭

| 칸 | 슬롯 |
| --- | --- |
| 테일 | 셔빗 200, 빅스핀 380, 비거스핀 520 |
| 가운데 뒤 | 노컴플라이 220, 노컴 빅스핀 450, 고스트라이드 150+ |
| 가운데 앞 | 피터팬 250, 피루엣 300, 바디 배리얼 280 |
| 노즈 | 180 피봇 300. 나머지 슬롯은 비어 있다 |

최소 속도는 트릭마다 0.2~0.3이다. 공중 판정이 있는 트릭은 셔빗 계열, 노컴 계열, 바디 배리얼이다.

걷기 한 칸이 끝나면 크로스스텝 20점이 조용히 더해진다. 이 점수는 콤보 개수와 피버 게이지에 들어가지 않고, 반복 감쇠도 없다. 노즈에 도착하면 노즈 워크 100점이 추가로 들어간다.

테일이 아닌 곳에서 속도가 0.05 미만이면 넘어진다. 넘어지는 중과 피봇 중에는 이 판정을 하지 않는다.

### 고스트라이드

가운데 뒤에서 시작한다. 내리는 동작 280ms 뒤 달리기. 달린 시간이 점수에 더해진다.

- 1번 버튼: 바로 올라타기. `150 + round(달린초 * 90)`
- 2번 버튼: 0.8초 넘긴 뒤에만 킥플립 캐치. `420 + 같은 보너스`
- 3.2초를 넘기면 보드를 놓쳐 넘어진다

끝나면 테일로 돌아온다.

### 180 피봇

노즈에서만. 약 650ms 동안 월드가 135px 더 전진하고, 끝나면 테일, 몸 방향 반전, 300점.

### 행텐 미터

타이밍 미터, 행텐 320 / 퍼펙트 600, 2.6초 안에 못 누르면 균형 상실로 넘어지는 처리가 있다. 이 동작을 시작하는 입력은 없다. 행파이브는 영어 이름만 있고 점수 처리가 없다.

## 점수

트릭 점수:

```
round(기본점 * max(0.25, 1 - 0.25 * 같은트릭횟수)) * (피버 중이면 2, 아니면 1)
```

같은 콤보에서 반복할수록 25%씩 줄고, 바닥은 25%다. 크로스스텝은 이 계산에서 빠진다.

콤보 확정:

```
획득 = combo.pts * max(1, combo.n)
```

확정 시점:

- 테일에서 푸시
- 테일에서 동작 없이 2초
- 세션 종료. 넘어지는 중으로 끝나면 확정하지 않고 버린다

피버 게이지는 트릭 점수 / 1600만큼 찬다. 1이 되면 7초 동안 점수 2배, 게이지는 0으로 리셋된다. 피버 중에는 게이지가 차지 않는다. 넘어지면 게이지가 절반이 된다.

도감 13종은 해당 트릭을 처음 성공하면 `landed`에 기록된다. 크로스스텝과 행텐은 도감 항목이 아니다.

## 돌

첫 돌은 월드 1100 근처, 이후 간격은 1250~2600이다. 돌이 트럭 위치(라이더 기준 47px 안)에 들어오면 판정한다.

| 상황 | 결과 |
| --- | --- |
| 공중 트릭의 공중 구간 | 돌 넘기 +100, 콤보 유지 |
| 고스트라이드 | 보드가 혼자 넘고 흔들림 |
| 피봇 | 피함 |
| 테일로 돌아오는 스텝이 60% 넘김 | 아슬아슬 통과 |
| 테일에 서 있거나, 푸시·테일 스핀 중 | 통과, 속도 8% 감소 |
| 그 외 | 돌빵. 콤보 상실, 속도 0, 보드가 돌을 지나 선 뒤 1.5초 후 테일 |

돌이 440px 안으로 다가오면 HUD에 돌 주의가 뜬다.

## 세션이 끝날 때

칭호는 이번 판 점수 기준이다.

| 점수 | 칭호 |
| --- | --- |
| 0 | 뉴비 |
| 3,000 | 동네 라이더 |
| 8,000 | 크루 에이스 |
| 15,000 | 댄싱 머신 |
| 25,000 | 전설의 라이더 |

로컬 최고 점수와 최고 콤보를 갱신한다. 결과 카드(1080×1350)는 현재 3D 화면 스냅샷 위에 점수, 칭호, 순위, 트릭 목록을 그린다.

## 저장

| 키 | 내용 |
| --- | --- |
| `darimit-session-3d.v1` | 최고 점수, 최고 콤보, 음소거, 카메라, 스팟, 도감 |
| `darimit-extra.v1` | 닉네임(12자), 데크, 휠, 음악, 이 기기 최근 기록 30개 |

스팟과 보드 색은 플레이 중에는 바꾸지 못한다.

## 랭킹과 공유

랭킹은 Supabase `scores`에서 점수 내림차순 200개를 가져와, 이름마다 최고 점수만 남긴 뒤 20개까지 보여 준다. 서버에 못 붙으면 이 기기 기록만 쓴다.

세션이 끝나면 이번 점수를 로컬에 넣고, 0점보다 크면 서버에도 넣는다. 순위는 다른 사람의 최고 기록과 이번 점수를 비교한다. 이번 판이 본인 최고면 그 순위가 보드 순위와 같다.

결과 링크는 10자 id로 JPEG(1200×630)을 `cards` 스토리지에 올리고 `shares`에 기록을 넣은 뒤 `https://minilongbd.netlify.app/s/<id>`를 만든다. HTML의 `#challenge-data`가 있으면 시작 화면에 그 기록을 보여주고, 스팟도 그 기록의 스팟으로 맞춘다.

## 화면과 소리

발 위치는 보드 길이 비율(`POS`)이고, 다리는 두 뼈 IK로 발에 맞춘다. 트릭 종류마다 `pose3`가 점프, 회전, 달리기 포즈를 만든다. 스팟은 다리 밑, 바닷가, 낮 시티이며 배경·안개·바닥만 바꾸고 규칙 수치는 같다.

효과음과 스팟별 루프 음악은 Web Audio다. 탭이나 키 입력 때 AudioContext를 연다. 탭이 숨으면 오디오를 잠시 멈춘다.

디버그용으로 `window.__game`에 `G`, `start`, `doInput`, `setCam`이 열려 있다.
