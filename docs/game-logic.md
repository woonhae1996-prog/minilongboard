# 보드를 타보자! 주요 로직

30초 롱보드 댄싱. 규칙은 `js/game.js`의 상태 `G`가 담당하고, Three.js는 그 상태를 자세와 배경으로 그린다. 한 프레임은 `update(dt)` → `render3d` → `hud` 순서다. `dt`는 최대 0.05초로 자른다.

## 회전 용어

이 프로젝트의 동작 설명에서는 다음 기준을 사용한다.

| 용어 | 정의 |
| --- | --- |
| `spin` | 보드가 180° 회전하는 동작. 360° 회전은 2 spin |
| `flip` | 보드가 가로로 한 바퀴(360°) 회전하는 동작 |

## 한 판

1. 시작 화면(`title`)에서 닉네임, 스팟, 데크, 휠을 고른다. 닉네임이 없으면 시작하지 않는다.
2. `start()`가 `G`를 `play`로 새로 만든다. 속도 `startSpeed = 0`, 남은 시간 30초, 위치는 `startPosition`(가운데 앞, `2`). 대기·결과 화면에도 같은 위치를 사용한다. 첫 푸시로 가속하기 전까지 속도 부족으로 넘어지지 않는다. 시작 자세는 pose 페이지의 가운데 앞 기본 서기 좌표 `POS[2]`를 사용한다.
3. 플레이 중 걷기, 푸시, 트릭으로 콤보를 쌓고 확정하면 점수에 들어간다.
4. 시간이 0이 되면 `endSession()`. 넘어지는 중이 아니면 남은 콤보를 확정하고 `over`로 바꾼다.
5. 결과 오버레이, 결과 카드, 랭킹 전송, 공유 링크가 이어진다.

WebGL 렌더러를 만들지 못하면 시작 화면 대신 오류 오버레이를 보여주고 루프를 돌리지 않는다.

## 주행 테스트

`ride.html`은 같은 게임 루프와 입력을 사용한다. `data-page="ride-test"`일 때 `rideTestSpeed = 0.5`로 속도를 고정하고 감속·푸시 가속·돌 통과 감속을 적용하지 않는다. 돌은 생성하거나 충돌 판정하지 않는다. 시작 화면 없이 바로 주행하며 트릭 도감은 숨긴다. 넘어짐과 복귀 중에도 같은 속도를 유지한다. 타이머는 경과 시간을 표시하며 시간 제한은 없다. 닉네임 없이 시작할 수 있고, 테스트용 저장 키를 사용하며 서버 랭킹에는 접근하지 않는다.

## 상태

| 필드 | 의미 |
| --- | --- |
| `mode` | `title` / `play` / `over` |
| `t` | 남은 초. 플레이 중에만 감소 |
| `v` | 속도 0~1. 초당 0.055씩 감소. 푸시 중반에 +0.24, 상한 1 |
| `worldX` | 보드가 굴러간 거리(px). `v * 300 * dt`만큼 증가 |
| `pos` | 발 위치. 0 테일, 1 가운데 뒤, 2 가운데 앞, 3 노즈 |
| `act` | 진행 중인 동작. 없으면 입력을 바로 받는다 |
| `combo` | `{pts, n, names, counts}` |
| `fever`, `gauge` | 피버 남은 초, 게이지 0~1 |
| `facing` | `0` = 레귤러(처음 방향), `1` = 구피(반대 방향). 180° 몸 회전 트릭마다 뒤집힌다 |

`title`과 `over`에서는 배경만 굴러간다. `over`는 속도가 초당 0.4씩 줄어든다.

## 스탠스와 발 위치 기준

발 위치 기준점은 `public/js/pose/foot-positions.js`의 `footPositions`에서 관리한다. `front`/`rear`는 보드 진행 방향 기준이며 `footPair`가 애니메이션 다리 A/B에 연결한다. 주행과 pose 페이지는 시작·기본 서기·걷기 착지에 같은 `POS` 좌표를 사용한다. 걷는 동안 두 발은 순서대로 이동한다. 푸시와 각 트릭의 준비·착지는 `POS`와 피봇 기준을 참조한다. 트릭의 회전 궤적과 지면 접촉 오프셋은 각 동작에서 상대값으로 계산한다.

점수가 있는 트릭은 마지막 10% 구간에서 해당 칸의 `POS` 발 위치로 착지한다. 착지할 때 A/B 다리의 앞뒤 순서는 현재 자세에 맞춰 유지하고, 다음 동작도 같은 `POS` 좌표에서 시작한다.

이 프로젝트에서는 게임 시작 시의 몸 방향을 **레귤러(Regular)**, 몸이 반대로 돌아간 방향을 **구피(Goofy)**로 정의한다. 이후 구현과 설명은 이 용어를 기준으로 한다. 새 게임은 레귤러(`G.facing = 0`)로 시작하며, 반대 방향은 구피(`G.facing = 1`)다.

발 위치의 좌우는 카메라가 아니라 보드의 진행 방향을 기준으로 한다. 현재 좌표계에서 진행 방향은 `+X`, 왼쪽은 `-Z`, 오른쪽은 `+Z`다. 보드 길이 방향 위치는 `POS`의 테일 `0` → 노즈 `1` 비율을 사용하고, 폭 방향 위치는 각 발의 `za`, `zb`로 지정한다.

크로스스텝(`js/pose/tricks.js`의 `poseStep`)은 이동 전용 발 경로(`crossStepPositions`)를 사용한다. 경로의 인접 위치마다 한 발은 지지발로 고정되고, 다른 발이 이동해 착지한다. 이 경로는 기본 자세의 `POS`와 별도로 관리한다.

| 스탠스 | 상태 | 움직이는 발의 경로 |
| --- | --- | --- |
| 레귤러 | `facing = 0`, `side = 1` | 보드 왼쪽(`-Z`)을 경유 |
| 구피 | `facing = 1`, `side = -1` | 보드 오른쪽(`+Z`)을 경유 |

`createPose3(env, getStance)`의 스탠스 매개변수는 `side`, `baseYaw`, `rotationSign`을 제공한다. 트릭은 레귤러 기준으로 계산한 뒤 구피에서 발·보드의 Z 좌표와 회전 부호를 함께 반전한다. 골반 연결은 최종 몸 방향에 대한 발 위치로 결정한다.

각 발의 폭 방향 이동은 해당 발의 이동 진행도에 따라 `-0.08 * side * sin(πt)`다. 스텝 중간에 옆으로 가장 멀리 이동하고, 착지하면 중앙(`Z = 0`)으로 복귀한다.

## 입력

버튼과 키보드는 같은 `doInput`으로 들어간다.

| 입력 | 키 | 조건 |
| --- | --- | --- |
| 뒤로 / 앞으로 | ← → | 테일~노즈 한 칸. 한 스텝 240ms |
| 푸시 | ↑, Z | 가운데 뒤·앞(1, 2)에서만. 560ms(`pushDuration`), 먼저 콤보를 확정 |
| 트릭 1·2·3 | 1 2 3, J K L, Space는 1번 | 화면에 나온 최대 3개. 최소 속도 미만이면 거절 |

동작 중 들어온 입력은 `queue`에 하나 저장했다가 동작이 끝나면 실행한다. 넘어진 중, 고스트라이드, 피봇 중에는 큐에 넣지 않는다. 고스트라이드 달리는 중에는 슬롯 버튼이 그 동작 전용이다.

플레이가 아닐 때 Enter, Space, R은 시작(다시하기)이다. V는 옆 시점과 뒤 시점을 바꾼다. 입력란에 포커스가 있으면 키는 무시한다.

도감과 자세 미리보기는 보드가 회전하거나 뒤집히는 **트릭**과, 보드는 그대로 두고 발걸음이나 몸동작을 잇는 **댄싱**으로 나눈다. 피봇과 고스트라이드 킥플립은 각각 보드 스핀과 플립이 있어 트릭에 포함한다. 피터팬, 망고, 스텝, 고스트라이드, 피루엣, 바디 배리얼은 댄싱에 포함한다. 댄싱 점수는 기존 점수의 70%로 낮추고 10점 단위로 반올림한다. 게임 동작 버튼은 트릭을 주황색, 댄싱을 민트색으로 구분한다.

트릭 고스트라이드 킥플립의 달리기 보너스는 `round(달린 초 × 90)`이다. 댄싱 고스트라이드는 달리기 보너스도 기존값의 70%를 10점 단위로 반올림한다. 표의 점수는 반복 감쇠와 피버 배율을 적용하기 전 값이다.

| 추가 점수 | 점수 | 조건 |
| --- | ---: | --- |
| 크로스스텝 | 10 | 한 칸 걷기 완료 |
| 노즈 워크 | 70 | 걷기로 노즈에 도착 |
| 돌 넘기 | 100 | 보드가 스핀하거나 플립하는 트릭의 공중 구간에 돌 통과 |

직접 선택할 수 있는 트릭이 3개 이하면 모두 보여 준다. 더 많으면 위 순서에서 3개만 무작위로 고르고, 고른 트릭은 그 순서를 유지한다. 트릭이 끝나면 같은 칸에서 다시 3개를 뽑는다. 다른 칸으로 옮기면 그 칸 목록으로 다시 고른다. 고스트라이드 킥플립은 고스트라이드 도중에만 선택할 수 있다.

최소 속도는 트릭마다 0.2~0.3이다. 돌넘기 공중 판정은 보드가 스핀하거나 플립하는 트릭에만 적용한다. 바디 배리얼은 몸만 회전하므로 제외한다.

푸시의 속도 증가량은 `PUSH_SPEED_BOOST` 하나로 관리한다. 연속 푸시는 2.5초 안에 이어지면 회당 기본 푸시 증가량의 1/6만큼 보너스가 늘고, 보너스 상한은 기본 증가량의 1/2이다(현재 회당 +0.04, 최대 +0.12, 푸시 총 증가 최대 +0.36). 다른 동작을 시작하거나 2.5초 동안 푸시하지 않으면 연속 횟수를 초기화한다. 댄싱 스킬을 성공적으로 마치면 공통 `applySpeedBoost`를 푸시의 50% 배율로 적용한다(기본 +0.12, 최대 1.0). 푸시 기본 증가량을 바꾸면 연속 보너스와 댄싱 증가량도 같은 비율로 따라가며, 동작 점수 팝업에 실제 속도 증가량을 함께 표시한다. 한 칸 걷기는 속도를 바꾸지 않는다. 걷기가 끝나면 크로스스텝 10점이 조용히 더해진다. 이 점수는 콤보 개수와 피버 게이지에 들어가지 않고, 반복 감쇠도 없다. 노즈에 도착하면 노즈 워크 70점이 추가로 들어간다.

첫 푸시로 출발한 뒤에는 위치와 관계없이 속도가 0.05 미만이면 넘어진다. 넘어지는 중과 피봇 중에는 이 판정을 하지 않는다. 넘어짐에서 복귀한 직후에는 다시 푸시할 때까지 판정을 잠시 보류한다.

### 고스트라이드

가운데 뒤에서 시작한다. 내리는 동작 280ms 뒤 달리기. 달린 시간이 점수에 더해진다.

- 1번 버튼: 바로 올라타기. 기본 60점에 달린 시간 보너스를 더한다. 보너스는 `round(달린초 × 90)`의 70%를 10점 단위로 반올림한다.
- 2번 버튼: 0.8초 넘긴 뒤에만 킥플립 캐치. `140 + round(달린초 × 90)` (트릭 점수라 감액하지 않음)
- 3.2초를 넘기면 보드를 놓쳐 넘어진다

두 동작 모두 올라타는 마지막 구간에 가운데 뒤 기본 발 위치로 이동하고, 착지 후 위치도 가운데 뒤가 된다.

### 180 피봇

노즈에서만. 약 650ms 동안 월드가 135px 더 전진하고, 끝나면 테일, 몸 방향 반전, 200점.

### 180 스텝

가운데 뒤에서 그 트릭이 뽑히면 실행한다. 680ms 동안 왼발을 오른발 앞꿈치의 보드 오른편에 수직으로 모으며 진행 방향을 본다. 이어 오른발을 반시계 방향으로 돌려 왼발의 노즈 쪽, 보드 폭 중앙에 놓으며 몸을 180° 회전한다. 구피에서는 대칭으로 처리한다. 보드는 회전하지 않으며 위치는 가운데 뒤를 유지한다. 착지하는 두 발의 위치는 고정된 가운데 뒤 기본 서기 좌표 `POS[1]`을 기준으로 한다. 완료하면 레귤러·구피가 전환되고 80점과 마무리 다운을 적용한다.

### 360 스텝

가운데 뒤에서 그 트릭이 뽑히면 실행한다. 180 스텝 뒤 오른발을 고정하고 왼발을 그 앞꿈치의 보드 왼편에 수직으로 모으며 상체는 진행 역방향을 본다. 이어 오른발을 시계 방향으로 돌려 고정된 가운데 뒤 기본 서기 좌표 `POS[1]`로 돌아온다. 보드는 회전하지 않고, 완료 시 몸 방향은 시작 방향과 같다. 구피는 대칭이며 동작 시간은 1200ms, 점수는 140점이다.

### 피터팬

가운데 앞에서 실행하며 총 1200ms의 네 구간으로 구성한다. 레귤러 기준 왼발을 오른발 앞꿈치로 모은 뒤, 왼발을 축으로 오른발이 바깥쪽 큰 원호를 그리며 교차한다. 오른발을 고정하고 왼발을 시계 방향으로 돌려 시작 위치에 놓으며 상체는 오른쪽 45°를 유지한다. 마지막에는 상체와 골반이 오른쪽 90°로 돌고 오른발도 뒤꿈치를 축으로 돌며 시작 위치로 돌아온다. 두 발끝은 보드 오른쪽을 향하며 구피는 대칭이다.

### 망고

가운데 앞에서 실행한다. 첫 두 구간은 피터팬의 1·2번 자세를 공통 함수로 재사용한다. 3번에서는 왼무릎을 15° 굽히고 오른발을 왼다리 오른쪽 허공에 띄운다. 4번부터 왼무릎을 40°까지 굽히며 상체를 앞으로 기울인다. 오른발은 지면을 따라 바깥쪽 곡선으로 테일 뒤와 왼쪽 바퀴 바깥까지 끌어온다. 상체는 오른쪽 45°에서 30°로 돌아간다. 6번에서 점프하고, 7번에서 점프 여파로 몸을 낮추며 오른발을 몸 쪽으로 더 끌어오고 주행 방향을 바라본다. 5~7번은 빠르게 이어지며 전체 동작은 1800ms이고 구피에서는 좌우가 대칭이다.

### 찹 더 우드

가운데 앞에서 실행한다. 레귤러에서는 왼발을 0~18% 구간에 짧게 들어 힐사이드 레일 가까이 놓고 데크 기준 발끝을 노즈 방향 10°로 돌린다. 왼발이 닿은 뒤 골반을 지지발 쪽으로 옮기고 무릎을 최대 약 55° 굽힌다. 25%부터 오른쪽 무릎을 기존 주행 자세보다 먼저 접어 오른발을 든 뒤, 테일과 토사이드 방향이 섞인 대각선으로 뻗으며 무릎을 약 18°까지 편다. 최대 신전 자세를 잠시 유지하고, 오른쪽 무릎을 다시 접어 78% 무렵 테일 쪽 착지점 바로 위로 회수한다. 이때 왼발은 데크에 고정되고 가슴은 노즈 쪽으로 열린 채 골반은 낮게 유지된다. 78~90% 구간에는 왼발로 가볍게 밀어 양발이 짧게 공중에 뜬다. 보드는 주행 높이를 유지하고 라이더만 최대 약 0.08 월드 단위 올라간다. 공중에서 양발의 위치와 각도, 가슴과 골반 방향을 기본 자세로 돌리고 90% 무렵 양발을 함께 내린다. 이후 짧게 무릎을 굽혀 충격을 흡수한다. 가슴은 기존 오른쪽(+Z)에서 노즈(+X) 쪽으로 최대 70°, 골반은 10° 돌린다. 상체는 골반 회전축과 독립적으로 데크의 +X 방향으로 약 12° 숙인다. 가슴 회전과 숙임은 오른발 최대 신전에서 최고점에 도달하고 홉 중에 기본 자세로 돌아간다. 구피에서는 진행축 기준 좌우가 반전되어 오른발이 지지발이다. 1100ms, 기본 점수 120점이다.

## 점수

트릭 점수:

```
round(기본점 * max(0.25, 1 - 0.25 * 같은트릭횟수)) * (피버 중이면 2, 아니면 1)
```

같은 콤보에서 반복할수록 25%씩 줄고, 바닥은 25%다. 크로스스텝은 이 계산에서 빠진다.

콤보 확정:

```
획득 = combo.pts * max(1, combo.n)
```

확정 시점:

- 가운데 뒤·앞에서 푸시
- 테일에서 동작 없이 2초
- 세션 종료. 넘어지는 중으로 끝나면 확정하지 않고 버린다

피버 게이지는 트릭 점수 / 1600만큼 찬다. 1이 되면 7초 동안 점수 2배, 게이지는 0으로 리셋된다. 피버 중에는 게이지가 차지 않는다. 넘어지면 게이지가 절반이 된다.

도감 항목은 해당 동작을 처음 성공하면 `landed`에 기록된다. 크로스스텝은 도감 항목이 아니다.

## 돌

첫 돌은 월드 1100 근처, 이후 간격은 1250~2600이다. 돌이 트럭 위치(라이더 기준 47px 안)에 들어오면 판정한다.

| 상황 | 결과 |
| --- | --- |
| 공중 트릭의 공중 구간 | 돌 넘기 +100, 콤보 유지 |
| 고스트라이드 | 보드가 혼자 넘고 흔들림 |
| 피봇 | 피함 |
| 테일로 돌아오는 스텝이 60% 넘김 | 아슬아슬 통과 |
| 테일에 서 있을 때 | 통과, 속도 8% 감소 |
| 그 외 | 돌빵. 콤보 상실, 속도 0, 보드가 돌을 지나 선 뒤 1.5초 후 시작 위치·자세로 복귀, 다시 푸시하기 전까지 속도 부족 넘어짐 보호 |

돌이 440px 안으로 다가오면 HUD에 돌 주의가 뜬다.

## 세션이 끝날 때

칭호는 이번 판 점수 기준이다.

| 점수 | 칭호 |
| --- | --- |
| 0 | 뉴비 |
| 3,000 | 동네 라이더 |
| 8,000 | 크루 에이스 |
| 15,000 | 댄싱 머신 |
| 25,000 | 전설의 라이더 |

로컬 최고 점수와 최고 콤보를 갱신한다. 결과 카드(1080×1350)는 현재 3D 화면 스냅샷 위에 점수, 칭호, 순위, 트릭 목록을 그린다.

## 저장

| 키 | 내용 |
| --- | --- |
| `darimit-session-3d.v1` | 최고 점수, 최고 콤보, 음소거, 카메라, 스팟, 도감 |
| `darimit-extra.v1` | 닉네임(12자), 데크, 휠, 음악, 이 기기 최근 기록 30개 |

스팟과 보드 색은 플레이 중에는 바꾸지 못한다.

## 랭킹과 공유

랭킹은 Supabase `scores`에서 점수 내림차순 200개를 가져와, 이름마다 최고 점수만 남긴 뒤 20개까지 보여 준다. 서버에 못 붙으면 이 기기 기록만 쓴다.

세션이 끝나면 이번 점수를 로컬에 넣고, 0점보다 크면 서버에도 넣는다. 순위는 다른 사람의 최고 기록과 이번 점수를 비교한다. 이번 판이 본인 최고면 그 순위가 보드 순위와 같다.

결과 링크는 10자 id로 JPEG(1200×630)을 `cards` 스토리지에 올리고 `shares`에 기록을 넣은 뒤 `<사이트 주소>/s/<id>`를 만든다. HTML의 `#challenge-data`가 있으면 시작 화면에 그 기록을 보여주고, 스팟도 그 기록의 스팟으로 맞춘다.

## 화면과 소리

발 위치는 보드 길이 비율(`POS`)이고, 다리는 두 뼈 IK로 발에 맞춘다. 트릭 종류마다 `pose3`가 점프, 회전, 달리기 포즈를 만든다. 스팟은 다리 밑, 바닷가, 낮 시티이며 배경·안개·바닥만 바꾸고 규칙 수치는 같다.

효과음과 스팟별 루프 음악은 Web Audio다. 탭이나 키 입력 때 AudioContext를 연다. 탭이 숨으면 오디오를 잠시 멈춘다.

디버그용으로 `window.__game`에 `G`, `start`, `doInput`, `setCam`이 열려 있다.
